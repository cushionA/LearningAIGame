# 前提

## 参考元ゲームとの比較

以下の引用への回答：

> どの部分を参考にしてどのようなゲームを作るのかの簡単な用件項目だけでも MTG までに洗い出していただけないでしょうか？

全般的に行動バリエーションを減らして、基礎となる読み合いの部分だけを抽出することを意識。

| 機能名                 | 機能説明                                                 | 有無                                                                       |
| :--------------------- | :------------------------------------------------------- | :------------------------------------------------------------------------- |
| **スタンスシステム**   | 上・右・左の 3 方向の構えを切り替える機能                | あり                                                                       |
| **攻撃アクション**     | 弱攻撃、強攻撃などの基本的な攻撃                         | 弱攻撃と強攻撃あり                                                         |
| **防御アクション**     | スタンスを合わせて防ぐブロックや、ステップで避けるドッジ | いずれもあり（回避派生の攻撃はなし）                                       |
| **リソース管理**       | 体力とスタミナの管理                                     | いずれもあり                                                               |
| **ガード崩し**         | ガードを無効化する「崩し」と、それに対応するアクション   | あり（用途が同じアクションが射撃。モーション的に崩しより実装コストは低い） |
| **高度な防御**         | 攻撃を弾いて反撃する「パリィ」                           | あり                                                                       |
| **連続攻撃のコンボ**   | 連続攻撃                                                 | なし（ボタン操作の組み合わせで特殊攻撃はない）                             |
| **攻撃のフェイント**   | 攻撃をキャンセルするフェイント                           | あり（AI の読み合いに使用させたい）                                        |
| **ターゲットシステム** | 特定の敵をロックオンする機能                             | あり（1vs1 のため常にロック、ロックオフなし）                              |

## 戦闘システム仕様書から廃止予定のアクション

参考：[戦闘システム仕様書](https://github.com/cushionA/LearningAIGame/blob/main/%E4%BB%95%E6%A7%98%E6%9B%B8/%E6%88%A6%E9%97%98%E3%82%B7%E3%82%B9%E3%83%86%E3%83%A0%E4%BB%95%E6%A7%98%E6%9B%B8.md)

| アクション名         | 廃止理由                                                                                                                    |
| :------------------- | :-------------------------------------------------------------------------------------------------------------------------- |
| **スキル**           | 実装コストが多く、LLM の判断上ノイズになるため                                                                              |
| **弱射撃**           | 当初ストーリーでエネミーと戦う場面を想定していたが、1vs1 の戦闘では不要と判断。射撃の弱強はなくなり、単体のアクションに統合 |
| **ブーストダッシュ** | ストーリーを想定して入れていた部分が大きいため、1vs1 の戦闘に最適化するため削除                                             |
| **武器システム**     | コストのわりにやりたいことを考えた時必須ではないため。余裕があれば復活希望                                                  |
| **ジャスト回避**     | 射撃へのメタであったため、弱射撃廃止により不要に                                                                            |
| **二段回避**         | ジャスト回避と同様の理由で廃止                                                                                              |
| **ジャンプ**         | 射撃戦を前提としたアクションであったため廃止                                                                                |
| **クイックターン**   | ジャンプとブースト廃止により、背後に回り込まれる恐れがなくなったため廃止                                                    |
| **防御モード**       | スキル前提の仕様だったため。エネルギー切れ時の仕様は低コストに変更                                                          |

## 基本システム

上、左、右のいずれかの方向で攻撃・防御を行える。

例：右からくる攻撃は右に防御することで防げる。左にガードしている相手に上から攻撃をすると通る。

## 攻撃システム

コンボという概念はなく、小さな読み合いを連続で続けていくイメージ。

### 弱攻撃

**概要**  
出が速い低威力近接攻撃。  
踏み込みあり。  
エネルギー消費有り。

**仕様**

- ヒット時の怯みあり
- ヒット後別の攻撃が確定することはないが、有利フレームはある（次の読み合いで被ダメージ側が若干不利になる）
- コンボの概念はなく、連打しても同じ攻撃が出るだけ
- モーションは上、左、右の弱攻撃が一種類ずつ。計三つ
- 後述の回避後先攻入力で回避硬直をキャンセルして発動可能  
  元ゲームの回避派生攻撃に似ているが、あくまで硬直をキャンセルして出しているだけなのでモーションが増えたりはしない

### 強攻撃

**概要**  
出が遅い高威力近接攻撃。  
踏み込みあり。  
キャンセル可能（別項で説明）。  
エネルギー消費有り。

**仕様**

- ヒット時に大きく怯むが、攻撃を出した方の後隙も大きいため、ちょうどニュートラルな状態で次の読み合いが始まる
- ヒット後別の攻撃が確定することはない
- コンボの概念はなく、連打しても同じ攻撃が出るだけ
- モーションは上、左、右の強攻撃が一種類ずつ。計三つ

### 強攻撃フェイント

**概要**  
強攻撃を中断するアクション。  
攻撃判定はない。  
強攻撃と誤認した相手のミスを誘うための読み合いパーツ。  
エネルギー消費有り。

**仕様**

- モーションは上、左、右の強攻撃が一種類ずつ。計三つ
- 強攻撃のモーションを途中でやめるモーション

## 防御システム

### ガード

**概要**  
何もしていないとき常にガード判定になる。  
上、左、右の内一方向だけガードすることができる。エネルギー消費なし。

**仕様**

- 弱攻撃ガード可能。弱攻撃が確定反撃
- 強攻撃ガード不能
- 射撃ガード可能。確定反撃なし
- 上、左、右の内、ガードを構えている方向が分かるように方向でモーションが変わる。三種類モーションが必要

### ブロッキング

**概要**  
元ゲームのパリィ。  
ガード状態でブロッキングボタンを押すと、ガード方向にブロッキング判定が出る。  
ブロッキング成功時エネルギー回復。  
失敗時エネルギー消費、かつ硬直に弱攻撃と射撃が確定する。  
失敗時のリスクがあるが、成功すると攻撃の主導権を奪える。

**仕様**

- 弱攻撃ブロッキング可能。強攻撃が確定反撃
- 強攻撃ブロッキング可能。弱攻撃が確定反撃
- 射撃ブロッキング可能。確定反撃なし
- 上、左、右のブロッキング方向でモーションが変わる。三種類モーションが必要

### ステップ回避

**概要**  
近接に対する無敵判定を出しながら任意方向にステップするアクション。元ゲームのドッジに相当する。エネルギー消費あり。

**仕様**

- 回避後に硬直がある
- 敵の方向を向いたまま飛ぶだけのモーション。一種類

### エネルギー

**概要**  
元ゲームのスタミナに相当。

**仕様**

- エネルギーは消費アクションをしていない間は常に回復する
- エネルギー切れになると高速回復するが、その間ブロッキングと攻撃が不可に
- 回避とガード、バックステップだけで耐える
