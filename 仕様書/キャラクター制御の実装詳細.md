# 実装箇所について

## 概要

キャラクター制御の全体像を以下としたとき、今回の実装部分は②と③です。

### キャラクター制御全体像

1. プレイヤーやAIが行動の入力を行う
   ↓
2. **入力に対応するアクションを実行する** ← 実装対象
   ↓
3. **アクションの開始時、終了時に戦況分析用データを状態管理クラスに報告する** ← 実装対象  
   （ここで報告したデータをもとにLLMが戦況分析・行動判断する）

ざっくり言うと入力に対するリアクション部分までを作ろうということです。

①の入力部分を後回しにするのは、AIの仕様がまだ固まっていないため、そちらの実装に関わらず使えるようなインターフェイスで②と③を作ってしまいたい意図です。

### 補足1. 状態管理クラスとは？

状態管理クラスは、そのキャラクターに関する情報を集積し、LLMへの状況報告やアニメーターパラメータの制御を行うクラス。

また、受け取った情報から各アクションを実行可能か、などのプロパティの値を更新する。（例：`IsAvoidable`プロパティの値が真なら回避可能、など）

これにより、行動実行クラスはプロパティの値だけを見て動作し、他クラスの存在を意識せずにいられる。

## 前提

先述の実装箇所を作るために、以下の二種類のクラスのインターフェイスを定義します。

1. **キャラクターコントローラー**（クラス名：`BattleCharacterController`）
2. **キャラクターの各種アクションの実装クラス**（クラス名：`BaseSystem<T>`クラス の派生クラス）

### 各クラスの役割

#### BattleCharacterController（責任範囲：入力受付、入力処理、移動処理）

1. **入力受付**  
   AIやプレイヤーからの入力を受け取る

2. **入力処理**  
   状態管理クラスに対し、そのアクションが実行可能な状態であるのかを問い合わせる。  
   実行可能なら各種`BaseSystem<T>`派生クラスのメソッドからアクション実行をトリガーする

3. **移動処理**  
   歩行制御を行う

#### BaseSystem<T>派生クラス

**責任範囲：** 行動関連報告、アクションに付随する移動

1. **行動関連報告**  
   アクションの開始、終了、成功/失敗などの情報をストリームに流す  
   （ストリームから状態管理クラスで処理）

2. **アクションに付随する移動**  
   `_moveController`を使い派生クラスで実装

### 補足2. なぜストリームを使うのか？

UniRxやR3といったリアクティブなAPIを使用すると、データの取得をクエリで柔軟にカスタマイズできるため。

また、各システムのインターフェイスを意識せずに流れてくるデータを処理すれば連携が可能になる。

### publicメソッド

#### WeakAttackAct()

- **引数：** なし
- **返り値：** `void`
- **機能：**  
  攻撃可能な状態かを確認後、以下の処理に分岐
  
  **実行可能な場合：**
  - `_actionSetting`からコストエネルギーを取得して`InternalEnergyUse()`に渡す
  - `_attackSystem`の弱攻撃実行メソッドを呼び出す
    - **引数：** ダメージ、踏み込みベクトルと踏み込み時間
    - ダメージは`_actionSetting`から取得したダメージ
    - 踏み込みベクトルは敵への法線ベクトルに`_actionSetting`から取得した踏み込み速度をかけた値
    - 踏み込み時間は`_actionSetting`から取得した踏み込み継続時間
  
  **実行不可な場合：**
  - 何もせずに戻る

#### HeavyAttackAct()

- **引数：** なし
- **返り値：** `void`
- **機能：**  
  攻撃可能な状態かを確認後、以下の処理に分岐
  
  **実行可能な場合：**
  - `_actionSetting`からコストエネルギーを取得して`InternalEnergyUse()`に渡す
  - `_attackSystem`の強攻撃実行メソッドを呼び出す
    - **引数：** ダメージ、踏み込みベクトルと踏み込み時間
    - ダメージは`_actionSetting`から取得したダメージ
    - 踏み込みベクトルは敵への法線ベクトルに`_actionSetting`から取得した踏み込み速度をかけた値
    - 踏み込み時間は`_actionSetting`から取得した踏み込み継続時間
  
  **実行不可な場合：**
  - 何もせずに戻る

#### HeavyAttackCancel()

- **引数：** なし
- **返り値：** `void`
- **機能：**  
  強攻撃実行中、かつキャンセル可能状態であるかを確認し、以下の処理に分岐
  
  **実行可能な場合：**
  - `_actionSetting`からキャンセルのコストのエネルギーを取得して`InternalEnergyUse()`に渡す
  - `_attackSystem`の強攻撃キャンセルメソッドを呼び出す
  
  **実行不可な場合：**
  - 何もせずに戻る

#### HeavyAttackFeint()

- **引数：** なし
- **返り値：** `UniTaskVoid`
- **機能：**  
  AIが使用する想定の強攻撃フェイントメソッド。  
  インスタンス内の`HeavyAttackAct()`を呼び出した後で、0.5秒ほど`await`して`HeavyAttackCancel()`を呼び出す  
  実行不可であっても、呼び出した二つのメソッドがそれぞれ何もしないので安全

#### ShootAct()

- **引数：** なし
- **返り値：** `void`
- **機能：**  
  攻撃可能な状態かを確認し、`_attackSystem`の射撃実行メソッドを呼び出す  
  実行不可であれば何もせずに戻る

#### GuardDirectionChange()

- **引数：** `Vector2 guardDirection`
- **返り値：** `void`
- **機能：**  
  ガード方向変更可能な状態かを確認し、以下の処理に分岐
  
  **実行可能な場合：**
  - `_defenseSystem`のガード方向変更メソッドを呼び出す
  - 引数は`guardDirection`
  
  **実行不可な場合：**
  - 何もせずに戻る

#### BlockingAct()

- **引数：** なし
- **返り値：** `void`
- **機能：**  
  ブロッキング可能な状態かを確認し以下の処理に分岐
  
  **実行可能な場合：**
  - `_defenseSystem`のブロッキング実行メソッドを呼び出す
  - `_actionSetting`からコストのエネルギーを取得して`InternalEnergyUse()`に渡す
  
  **実行不可な場合：**
  - 何もせずに戻る

#### AvoidAct()

- **引数：** `Vector2 moveVector`
- **返り値：** `void`
- **機能：**  
  回避可能な状態かを確認し、以下の処理に分岐する
  
  **実行可能な場合：**
  - `_actionSetting`からコストのエネルギーを取得して`InternalEnergyUse()`に渡す
  - `_defenseSystem`の回避実行メソッドを呼び出し、`_actionSetting`から取得した回避ベクトルと回避継続時間を渡す
    - 回避ベクトルはジョイスティック等の入力（`moveVector`）に`_actionSetting`から取得した回避速度をかけた値
    - 回避継続時間は`_actionSetting`から取得した回避継続時間
  
  **実行不可な場合：**
  - 何もせずに戻る

#### MoveAct()

- **引数：** `Vector2 moveVector`
- **返り値：** `void`
- **機能：**  
  移動可能な状態かを確認し、以下の処理に分岐する
  
  **実行可能な場合：**
  - `MoveController.MoveStart()`を呼び出して引数に移動ベクトルを渡す
  - 移動ベクトルはジョイスティック等の入力（`moveVector`）に`_actionSetting`から取得した移動速度をかけた値を使用
  
  **実行不可な場合：**
  - 何もせずに戻る

#### InternalEnergyUse()

- **引数：** `float useAmount`
- **機能：**  
  状態管理システムにあるエネルギーのプロパティの値を`useAmount`だけ減らす  
  エネルギー切れになれば状態管理システムのプロパティに反映されるため、返り値などは不要

### 使用クラス

#### MoveController

- **クラス名：** `MoveController`
- **ベースクラス：** `MonoBehaviour`
- **存在ファイル：** `MoveController.cs`
- **名前空間：** `LearningAIGame.CombatSystem.Core`
- **責任範囲：** 移動速度管理

**移動速度管理：**  
移動ベクトルを受け取り、時間経過などを加味した速度をRigidBodyに反映する

##### MoveControllerで使用する列挙型

```csharp
enum MoveType
{
    Velocity,  // 速度を直接変更したような等速運動（今回の通常移動はこちら）
    AddForce,  // 力を加えたような加速度付き運動（回避など）
    None       // 停止中
}
```

##### MoveControllerのprivateフィールド

- `RigidBody _rb`：移動処理に使用する
- `float _moveStartTime`：移動処理の際、移動開始した時間を記録する。移動開始時間と数学関数を使用し、移動速度に加速度付けをするため
- `float _moveDuration`：移動処理の際、その移動が継続する時間を記録する。加速度付けに使用
- `Vector2 _moveDirection`：移動ベクトル
- `MoveType _moveType`：移動の種類

##### MoveControllerのPublicメソッド

###### MoveStart()

- **引数：** `Vector2 moveVector`
- **返り値：** `void`
- **機能：**
  - `_moveVector`に`moveVector`を代入
  - `_moveType`に`Velocity`を代入
  - `_moveDuration`に0を代入

###### AddForce()

- **引数：** `Vector2 moveVector, float moveDuration`
- **返り値：** `void`
- **機能：**
  - `_moveVector`に`moveVector`を代入
  - `_moveStartTime`に現在の`Time.time`を代入
  - `_moveDuration`に`moveDuration`を代入
  - `_moveType`を`AddForce`に設定

###### Stop()

- **引数：** なし
- **返り値：** `void`
- **機能：**
  - `_moveType`を`None`に設定

##### MoveControllerのprivateメソッド

###### InternalCalcSpeed()

- **引数：** なし
- **返り値：** `void`
- **機能：**  
  `FixedUpdate()`の最後に毎フレーム呼び出す
  
  移動タイプが`None`の場合何もせず早期リターン
  
  早期リターンしない場合、移動タイプによって以下の処理に分岐：
  
  **移動タイプが`Velocity`の場合：**
  - `_rb`の速度に`_moveVector`を設定
  
  **移動タイプが`AddForce`の場合：**
  - `_rb`の速度に`_moveVector * Math.Sin(((Time.time - _moveStartTime) / _moveDuration) * Math.PI)`を設定
  
  上記終了後、`Time.time - _moveStartTime`が`_moveDuration`を超えていたら`_moveVector`に`Vector2.zero`を代入し、`_moveType`を`None`に設定

## クラス名：AttackSystem

- **ベースクラス：** `BaseSystem<AttackInfo>`
- **存在ファイル：** `AttackSystem.cs`
- **名前空間：** `LearningAIGame.CombatSystem.Systems`
- **責任範囲：** 攻撃関連の報告、アクションに付随する移動

1. **攻撃関連の報告**  
   その時の攻撃方向や攻撃種類、ダメージなどで`AttackInfo`を作成し状態管理システム向けのストリームに流す

2. **アクションに付随する移動**  
   攻撃で踏み込む際に移動を行う

### AttackInfo構造体（状態管理システムへの報告用）

```csharp
public struct AttackInfo
{
    public StanceType stance;           // 上、左、右の攻撃方向
    public float damage;                // ダメージの値
    public bool isHeavy;               // 真なら強攻撃
    public AttackReportType reportType; // 開始、キャンセル、のどれか
}
```

### AttackSystemのPublicメソッド

#### WeakAttack()

- **引数：** `float damage, Vector2 moveVector, float moveDuration`
- **返り値：** `void`
- **機能：**
  - `_moveController.AddForce`を実行し、引数に`moveVector`と`moveDuration`を渡す
  - 攻撃開始を`NotifyObservers()`で状態管理クラスに通知

#### HeavyAttack()

- **引数：** `float damage, Vector2 moveVector, float moveDuration`
- **返り値：** `void`
- **機能：**
  - `_moveController.AddForce`を実行し、引数に`moveVector`と`moveDuration`を渡す
  - 攻撃開始を`NotifyObservers()`で状態管理クラスに通知

#### HeavyAttackCancel()

- **引数：** なし
- **返り値：** `void`
- **機能：**
  - `_moveController.Stop()`を実行して停止
  - 攻撃キャンセルを状態管理クラスに通知
